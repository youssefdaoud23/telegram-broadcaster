# Telegram Broadcaster

Self-hosted personal Telegram broadcast dashboard.

The app will provide a password-protected web UI for managing Telegram accounts, opted-in contacts, composing private messages, and viewing delivery results.

**Security:** Telegram API hashes, personal session files, app encryption keys, admin credentials, customer contacts, and delivery databases must remain on the server and must never be committed to this public repository.

Existing n8n and Telethon services are not replaced automatically; deployment uses a separate application and database.
