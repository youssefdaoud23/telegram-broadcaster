Connect a Telegram account

A guided setup for your personal Telegram identity. No bot token required.

STEP 1 OF 2

Get your API credentials

Telegram provides your application's API ID and Hash. These are different from a BotFather token.

1
Open Telegram's official developer portal

Visit my.telegram.org/apps ↗.

2
Sign in with your phone number

Use the personal Telegram account you want to send from.

3
Create an API application

Open API Development Tools. Add an app title and short name; choose an appropriate platform such as Bot / Server.

4
Copy your API ID and API Hash

Enter them in the secure form. Never store them in GitHub.

You can use the same Telegram API application for more than one account. Each account gets a separate encrypted profile and Telegram session file.
STEP 2 OF 2

Save your Telegram account

Once saved, we'll request a Telegram verification code.

🔒

Your API Hash and phone are encrypted at rest. Telegram login codes and 2FA passwords are never stored.
